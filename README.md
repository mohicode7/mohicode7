## 💫 About Me

I'm a **Structural Engineer** turned **software developer**, building the tools that structural and seismic engineers actually use every day.

- 🏗️ Structural Engineer specializing in **seismic design** and **finite element analysis**
- 💻 **.NET & Python** developer, crafting engineering-grade software (WPF desktop apps, reusable libraries, APIs)
- 🎯 Deep focus on **ASCE 7**, **AISC 360**, and **INBC** based seismic workflows
- 🧩 Passionate about clean **software architecture**: modular, testable, standards-compliant engineering libraries
